# BlackJackApp

BlackJackApp is gemaakt voor de Paradigma Challenge van de course
Algorithms, Programming Languages and Paradigms.

Voor deze challenge heb ik Clojure onderzocht en een Blackjack-algoritme
gemaakt dat berekent wat de kans is om bust te gaan bij het trekken van
een nieuwe kaart.
