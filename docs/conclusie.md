# Conclusie

Tijdens deze challenge heb ik vooral geleerd om op een andere manier naar programmeren te kijken. In het begin vond ik Clojure erg lastig, omdat de syntax en manier van werken heel anders waren dan ik gewend ben van Java en JavaScript.

Door zelf problemen tegen te komen en deze stap voor stap op te lossen, merkte ik dat ik Clojure steeds beter begon te begrijpen. Ik heb geleerd om niet meteen terug te vallen op de manier waarop ik normaal zou programmeren, maar eerst na te denken over hoe ik een probleem functioneel kan oplossen.

Door mijn Blackjack-algoritme heb ik leren werken met onder andere `map`, `reduce`, `loop` en `recur` en begrijp ik concepten zoals immutability en pure functions beter. Persoonlijk heb ik vooral geleerd om door te zetten wanneer een nieuwe programmeertaal in het begin niet direct duidelijk is en open te staan voor andere manieren van programmeren. Hier heb ik altijd moeite mee gehad, maar ik merk dat ik er nu meer plezier in heb gekregen. Ik ben hierdoor ook meer gaan nadenken over hoe ik mijn code kan verbeteren en optimaliseren.
