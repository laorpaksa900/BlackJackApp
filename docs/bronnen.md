# Bronnen

Tijdens het onderzoeken van Clojure en functioneel programmeren heb ik de
volgende bronnen gebruikt.

## Clojure

- [Clojure - Rationale](https://clojure.org/about/rationale)  
  Gebruikt voor algemene informatie over Clojure en waarom de taal is ontwikkeld.

- [Clojure - Functional Programming](https://clojure.org/about/functional_programming)  
  Gebruikt voor informatie over functioneel programmeren, pure functions,
  first-class functions, immutable data structures en recursive looping.

- [Clojure - Higher Order Functions](https://clojure.org/guides/higher_order_functions)  
  Gebruikt voor informatie over higher-order functions en het meegeven van
  functies aan andere functies.

- [Clojure - Sequences](https://clojure.org/reference/sequences)  
  Gebruikt voor informatie over sequences en functies zoals `map`, `filter`
  en `reduce`.

- [Clojure - Reader](https://clojure.org/reference/reader)  
  Gebruikt voor informatie over de syntax van Clojure en symbols.

- [Clojure - Destructuring](https://clojure.org/guides/destructuring)  
  Gebruikt voor informatie over destructuring van collecties.

## Clojure functies

- [ClojureDocs - defn](https://clojuredocs.org/clojure.core/defn)  
  Gebruikt voor het maken van functies.

- [ClojureDocs - recur](https://clojuredocs.org/clojure.core/recur)  
  Gebruikt voor recursion en herhaling met `recur`.

- [ClojureDocs - let](https://clojuredocs.org/clojure.core/let)  
  Gebruikt voor het tijdelijk opslaan van waarden binnen een functie.

- [ClojureDocs - cond](https://clojuredocs.org/clojure.core/cond)  
  Gebruikt voor het uitvoeren van verschillende stukken code op basis van
  voorwaarden.

- [ClojureDocs - map](https://clojuredocs.org/clojure.core/map)  
  Gebruikt voor het uitvoeren van een functie op de waarden van een collectie.

- [ClojureDocs - filter](https://clojuredocs.org/clojure.core/filter)  
  Gebruikt voor het filteren van waarden uit een collectie.

- [ClojureDocs - reduce](https://clojuredocs.org/clojure.core/reduce)  
  Gebruikt voor het verwerken van meerdere waarden uit een collectie tot één
  resultaat.

- [ClojureDocs - fn](https://clojuredocs.org/clojure.core/fn)  
  Gebruikt voor informatie over functies in Clojure.
