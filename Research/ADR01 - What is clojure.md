# Wat is Clojure?

Clojure is gebaseerd op Lisp, een oude programmeertaal.
Het stimuleert functioneel programmeren en maakt veel gebruik van **immutability**.
Clojure heeft daarnaast een ingebouwd **concurrency model**.

## Functional programming

Clojure stimuleert het gebruik van functioneel programmeren. Hierbij wordt zoveel mogelijk gewerkt met functies en immutable data.

## Immutability

Clojure maakt gebruik van **immutable persistent data structures**. Immutable betekent dat bestaande data niet direct wordt aangepast. In plaats daarvan wordt er een nieuwe versie van de data gemaakt.

## Concurrency

Clojure heeft ingebouwde ondersteuning voor **concurrency**.

## Star Quote van Clojure
Functional programming is a good thing and Object Orientation is overrated
